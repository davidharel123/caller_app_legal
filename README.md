# caller_app_legal

The public legal pages for the BlindInOut Voice Caller Android app (project: `caller_app`).

- `privacy-policy.html` and `terms-of-use.html` (English and Hebrew) are published with GitHub Pages and linked from the app (Settings) and from the Google Play listing.
- This is the single source of truth for these two pages. Edit them here, not in the app repo.
- When the app's data handling changes (permissions, servers, trial/billing), update the privacy policy here in the same change.
- Pages needs this repo to be public. Address: `https://davidharel123.github.io/caller_app_legal/`
